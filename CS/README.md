Study computer-science foundations, research topics, and engineering practice. Topics may include algorithms, operating systems, networks, databases, architecture, programming languages, distributed systems, and relevant papers.

Read [instructions/router.md](instructions/router.md) and only the relevant task instructions.

- [常用指令速查](instructions/commands.md)：按学习目标选择可复制的指令。

- [session-log.md](session-log.md): concise meaningful practice history.

Say `知识点复习` to start [book-based review](instructions/book-review.md): choose a book, receive one concept selected from your learning history, discuss questions, and request a test when ready. Learning and assessment progress are recorded separately; explanation alone does not establish mastery.

Use existing materials first. If there are none for the requested topic, teach or practice it directly and save reusable notes when useful. Do not assume an empty record means no prior knowledge. Language-focused technical expression belongs in English; interview drills belong in interview.
