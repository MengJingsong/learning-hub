# Review Mode

Trigger: the user says “复习” or clearly asks to review study materials.

Read:
- `/english/english-study/README.md`;
- relevant files in `/english/study-materials/`;
- `/english/english-study/mastery.md`.

Select review items in this order:
1. due/overdue;
2. recently failed or weak;
3. low mastery;
4. not tested for a long time;
5. tier priority: Core > Useful > Specialized.

For a balanced session, roughly target 60% Core, 30% Useful, and 10% Specialized unless mastery data suggests otherwise.

Use active recall rather than recognition whenever possible.
