# Review

Trigger: the user says “复习” or clearly asks to review study materials.

Read:
- `/english/english-study/README.md`;
- relevant files in `/english/study-materials/`;
- `/english/english-study/mastery.md`.

Select review items in this order:
1. due/overdue;
2. recently failed or weak;
3. low mastery;
4. not tested for a long time;
5. tier priority: Core > Useful > Specialized.

For a balanced session, roughly target 60% Core, 30% Useful, and 10% Specialized unless mastery data suggests otherwise.

Read `/english/english-study/learning-plan.md` for the learner's current preference. When reviewing an entry in the explanation-led walkthrough, consult its exact-heading note under `/english/study-materials/explanations/` and base the explanation on that documentation, adding context-specific clarification as useful. Use active recall or quizzes when the learner explicitly requests practice or assessment.

Read `coaching.md`. Use `english-learning-coach` and `study.md` for vocabulary, phrases, and grammar. Use `english-speaking-coach` with `speaking.md` or `listening.md` for speaking or listening review. If the request gives no modality, continue the active exercise or begin with due vocabulary, phrases, and grammatical structures. Save meaningful evidence using the shared record rules.
