# Distributed System Instruction Router

Read `/Job/Distributed System/README.md` and `/Job/instructions/learning.md` for the shared teaching, review, and assessment workflow. Use only relevant existing materials; if none match, teach the requested topic directly. New reusable topic notes belong under `/Job/Distributed System/`; link existing CS notes rather than duplicating them.

For this course, read the [Distributed Systems Learning Plan](../Distributed-Systems-Learning-Plan.md) and the [session log](../session-log.md) before teaching or reviewing, and read [mastery](../mastery.md) before selecting a topic or assessing. Follow the plan's course-specific rules: Chinese–English treatment of main points, difficult points, key points, concepts, long sentences, and elliptical sentences; the figure rule (show the original figure when the PDF is locally accessible, otherwise redraw it and label it as redrawn); Hadoop and Cassandra as running examples; and saving the session log to GitHub after every explanation. These rules apply to follow-up explanations and take precedence over the shared guidance on how many English terms to include and when to record progress.

学习 / 学习模式: teach a selected concept. 复习 / 复习模式: retrieve and explain studied concepts. 测试 / 测试模式: assess independently using new problems. Keep any existing CS learning records in place; record meaningful evidence with an explicit topic reference, never infer mastery from an explanation alone.

Task modes persist within this conversation and category. A category switch clears the previous task mode; explicit tasks override it for that request. `默认模式` clears category and mode and returns to `/router.md`. Ask for a topic only if neither the request nor existing materials supplies one. Interview drills follow `/Job/interview/instructions/router.md`; language-focused practice follows English. `知识点复习` retains the root router's CS book-review workflow.
