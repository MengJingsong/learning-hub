# Distributed System Instruction Router

Read `/Job/Distributed System/README.md` and `/Job/CS/instructions/learning.md` for the shared teaching, review, and assessment workflow. Use only relevant existing materials; if none match, teach the requested topic directly. New reusable topic notes belong under `/Job/Distributed System/`; link existing CS notes rather than duplicating them.

学习 / 学习模式: teach a selected concept. 复习 / 复习模式: retrieve and explain studied concepts. 测试 / 测试模式: assess independently using new problems. Keep any existing CS learning records in place; record meaningful evidence with an explicit topic reference, never infer mastery from an explanation alone.

Task modes persist within this conversation and category. A category switch clears the previous task mode; explicit tasks override it for that request. `默认模式` clears category and mode and returns to `/router.md`. Ask for a topic only if neither the request nor existing materials supplies one. Interview drills follow `/Job/interview/instructions/router.md`; language-focused practice follows English. `知识点复习` retains the root router's CS book-review workflow.
