# Google AI Agent 开发资料

| 顺序 | 资料 | 用途 |
|---|---|---|
| 1 | [Agents overview](https://docs.cloud.google.com/gemini-enterprise-agent-platform/agents) | Agent Platform 的产品概览、ADK 与托管运行时的角色 |
| 2 | [Agent Development Kit (ADK)](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/adk) | ADK 的构建、调试、部署和评估能力 |
| 3 | [Develop an ADK agent](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/runtime/create-an-adk-agent) | 定义模型、工具、sessions 和 memory |
| 4 | [ADK quickstart: deploy on Agent Runtime](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/runtime/quickstart-adk) | 创建、测试和部署 ADK Agent |
| 5 | [Agent evaluation](https://docs.cloud.google.com/gemini-enterprise-agent-platform/optimize/evaluation/agent-evaluation) | Agent 表现、安全和质量的评估流程 |
| 6 | [Evaluate your agents](https://docs.cloud.google.com/gemini-enterprise-agent-platform/optimize/evaluation/evaluate-agents) | 使用 Google Cloud console 或 SDK 执行评估 |

资料覆盖 ADK 与 Google Cloud 运行环境。学习通用 Agent 概念时把框架特性与通用机制分开；实际开发时核对文档所要求的 SDK 版本、服务名称和部署前提。
