## 学习目标

能够用 Google ADK 建立一个有工具和会话状态的 Agent，解释本地开发与托管运行环境之间的区别，并用官方评估流程检查 Agent 质量。

## 学习路线

| 阶段 | 资料与主题 | 学习产出 |
|---|---|---|
| 1. 平台与框架 | Agents overview、ADK 概览 | 区分 ADK、Agent Platform Runtime 与模型服务职责 |
| 2. Agent 构建 | Develop an ADK agent | 建立 Agent，配置模型和工具，解释 session 与 memory 的用途 |
| 3. 测试与部署 | ADK quickstart | 在本地运行测试，再部署到 Agent Runtime，记录环境与版本要求 |
| 4. 质量评估 | Agent evaluation、Evaluate your agents | 设计测试用例和评分标准，分析失败轨迹并提出改进 |

## 每次学习

1. 从 checkpoint 恢复，核对本节官方文档。
2. 用中文解释概念、机制、演示与限制，一次围绕一个概念练习。
3. 把少量主题相关的英文词语、搭配、语法或句式自然放进讲解，在相关处简释意义和用法；需要时给短例句，不另设英语环节，不输出独立词表，也不硬塞表达。
4. 只有值得长期复习的表达才去重后加入 English study inbox。
5. 依据学习者真实回答或操作更新进度；计划使用 Learning Skill 与 Agent Tutor skill 中适用的学习方法，记录遵循 Learning Hub 规则。
