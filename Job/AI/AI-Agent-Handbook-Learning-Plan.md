# AI Agent Handbook 学习计划

**主要资料：** [AI Agent Handbook 阅读地图](AI-Agent-Handbook-Reading-Map.md)  
**原始手册：** https://aliyun.github.io/ai-agent-handbook/  
**全书目录：** https://aliyun.github.io/ai-agent-handbook/contents.html  
**计划更新：** 2026-11-13

## 学习目标

完成学习后，我希望能够：

- 描述企业级 Agent 应用的主要架构组成和职责边界。
- 解释 Harness 如何组织任务、上下文、状态、工具调用和行动。
- 分析 Agent 从一次请求扩展到异步、长程、多 Agent 系统时遇到的运行与通信问题。
- 说明如何通过可观测性、安全、资产管理和质量验证治理 Agent。
- 理解轨迹数据、黄金数据集和 Badcase 如何支持评估与持续改进。
- 将手册中的设计原则应用到具体 Agent 场景，并说明适用条件和取舍。
- 学会使用手册中的专业英文术语和自然表达；有长期价值的表达经过去重后加入 English study inbox。

## 节奏

计划分为 8 个模块。每个模块按小节学习，可用一周或更长时间完成；每次学习聚焦一个或少数几个概念。进度按理解证据推进，不要求固定的每周课时。手册会更新，开始每个模块时应查看在线目录和对应章节。

## 学习路线

| 模块 | 章节 | 学习重点 | 完成时应能做到 |
|---|---:|---|---|
| 1. 架构基础 | 1–2 | AI 原生应用；Agentic Application 参考架构；组件和责任边界 | 画出主要组件关系，并解释为何采用该架构 |
| 2. Harness 与任务 | 3–4 | Harness 的构建范式；任务编排、长程推进、协作流转 | 追踪一个任务从接收、拆解到完成的控制流程 |
| 3. 信息与行动 | 5–6 | 上下文、状态、可复用能力资产；受控行动、验证反馈、交付准备 | 说明 Agent 如何取得信息、调用工具、校验结果并准备交付 |
| 4. 可靠运行 | 7–9 | 运行时与沙箱；状态存储；AI 网关和统一流量治理、智能路由 | 分析隔离、状态持久化、模型路由的机制与限制 |
| 5. 自动化与协作 | 10–12 | 异步任务；自动化流程；Multi-Agent 协作；分布式通信 | 比较单 Agent 与多 Agent 流程，并分析超时、故障和消息交换 |
| 6. 治理与质量 | 13–16 | 可观测性、安全、AI 资产发现管理、行为生成与质量验证 | 为一个 Agent 设计可观测性、安全边界和质量检查 |
| 7. 调优与评估 | 17–24 | 模型与 Agent 调优；轨迹数据；运行时数据；黄金数据集；Badcase；受控自进化；边缘运行时 | 从一个运行问题出发，提出可验证的数据收集、评估和改进闭环 |
| 8. 实践与展望 | 25–30 | 企业实践案例；研发、设计、运维、安全、运营、多 Agent 基础设施；Agentic OS | 将前述原则映射到一个案例，并指出证据、约束和未解决问题 |

### 建议的重点顺序

优先深入模块 1–6，建立架构、Harness、上下文/状态、行动、可靠运行和治理基础。模块 7 是评估与优化主线，需结合具体运行场景学习。模块 8 以案例迁移为主，可选择与个人兴趣最接近的案例。

RAG 可以作为贯穿示例，用来讨论检索上下文、状态和工具行动；如果手册某章没有具体覆盖某个 RAG 机制，应明确标注为补充内容，而不把它归为手册结论。

## 每次学习的流程

1. 从本计划的 checkpoint 恢复，必要时先用一个简短问题回忆已学概念。
2. 定位在线手册的章节和小节，确认本次范围。
3. 用中文讲直觉和问题背景，再给准确术语、机制、前提和限制。
4. 用章节中的例子或明确标记的补充场景演示流程。
5. 分析失败模式、安全边界和设计取舍。
6. 一次提出一个解释、追踪或迁移问题，并等我作答。
7. 根据我的回答指出正确部分和具体缺口；必要时换一种解释后让我再试。
8. 每个重要概念配少量专业英文词语、搭配或句型；检查重复后，把值得长期学习的项目加入 English study inbox。
9. 更新本文件的进度记录和下一步。

回答默认用中文，保留标准英文术语。区分手册明确写出的内容、我的推论和外部补充资料。涉及易变的模型、API 或产品细节时，核对一手资料。

## 进度记录规则

本文件是 AI Agent Handbook 课程唯一的进度主档。不要为同一课程另建并行的笔记或掌握度系统。

每次完成一个有意义的学习单元，记录章节、概念状态、理解证据、待回顾问题、英语 inbox 项目和下一步：

- **Planned:** 已列入路线，尚未学习。
- **Introduced:** 已讲解，尚未通过回答检验。
- **Practiced:** 本次尝试过，保留具体困难。
- **Demonstrated:** 能独立解释、追踪、比较或应用，并记录证据。
- **Retention checked:** 后续学习时能延迟回忆或迁移应用。

不把听过讲解或表示“理解了”记作掌握。只在实际回答中观察到证据后，更新状态；后续回忆成功后再记录保持情况。
