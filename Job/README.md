| [interview/](interview/README.md) | 面试技巧、答题结构、行为面试、编码与系统设计模拟 | [Interview router](interview/instructions/router.md) |
| [CS/](CS/README.md) | 算法、操作系统、网络、数据库等基础计算机知识点 | [CS router](CS/instructions/router.md) |

## 如何寻找指令

1. 从仓库根目录 [router.md](../router.md) 选择学习类别；求职准备总入口是 [Job router](instructions/router.md)。
2. 职业规划、职业发展、岗位选择、技能差距分析或职业复盘请求，先通过 Job router 定位到 [career-development.md](career-development.md)；维护规则见该文件“使用与维护”。其他任务阅读对应子目录 README 和 `instructions/router.md`，再按任务读取具体指令。
3. CS 常用指令见 [commands.md](CS/instructions/commands.md)；书籍知识点复习见 [book-review.md](CS/instructions/book-review.md)；面试练习见 [preparation.md](interview/instructions/preparation.md)。
4. `Job模式` / `求职模式` 进入求职准备；`分布式模式` / `AI模式` 选择专题。`CS模式`、`面试模式`、`知识点复习` 等原有命令继续有效。`默认模式` 清除当前类别及任务模式。

## 与已有资料的关系

`Job/CS/` 和 `Job/interview/` 统一维护完整资料、指令及学习记录。原根目录内容已迁移至此；请直接在对应 Job 子目录维护，避免重复状态。

按主要学习目标归档：概念与原理放 CS、Distributed System 或 AI；模拟问答与面试表现放 interview；语言表达训练走 [English router](../english/instructions/router.md)。跨主题内容优先链接，避免重复维护。掌握度仅根据实际学习或测试证据记录，不因创建目录而推断。
