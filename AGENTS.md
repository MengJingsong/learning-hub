Start with the [root README](README.md). Follow its navigation to select the relevant category and read that category's README and task instructions. Default repository: `MengJingsong/learning-hub`.

English learning content and metadata live under `/english/`; computer-science learning lives under `/Job/CS/`; interview preparation lives under `/Job/interview/`. Keep category state separate and preserve existing learning records. See `/project-instructions.md` for copy-ready ChatGPT Project settings.

Job preparation starts at `/Job/README.md` and `/Job/instructions/router.md`, which route to `/Job/interview/`, `/Job/CS/`, `/Job/Distributed System/`, and `/Job/AI/`. CS and interview instructions, materials, and learning records are maintained in their Job directories; preserve one authoritative copy of each record.
